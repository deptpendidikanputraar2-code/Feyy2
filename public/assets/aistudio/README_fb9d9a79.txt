PAKET PWA UTUH SIAP PAKAI — MMQA AL RIFAI 02 (AR2)
====================================================
Daftar File dalam Paket ZIP:
1. index.html    -> Halaman utama aplikasi PWA lengkap
2. manifest.json -> Konfigurasi instalasi PWA & ikon aplikasi
3. sw.js         -> Service Worker mode offline
4. Code.gs       -> Backend Google Apps Script (untuk Google Sheets)
5. logo.png      -> Logo utama MMQA Al Rifai 02 (512x512)
6. icon-192.png  -> Ikon instalasi PWA 192x192
7. icon-512.png  -> Ikon instalasi PWA 512x512

Cara Pemasangan Hosting:
- Ekstrak seluruh file ke satu folder hosting Anda (Netlify, Vercel, GitHub Pages, atau cPanel).
- Buka URL hosting di browser HP/Desktop lalu pilih "Install Aplikasi / Tambahkan ke Layar Utama".
